4. FinBERT Financial Sentiment Analysis API



  Dedicated financial sentiment analysis using domain-adapted FinBERT. 
  Returns a continuous sentiment score normalized in [-1.0, +1.0] along with full probability distributions (positive, negative, neutral).





  
  

  







  How to Call Sentiment API (Code Examples)
  
# cURL (POST /sentiment)
curl -X POST "http://localhost:8000/sentiment" \
  -H "Content-Type: application/json" \
  -d '{"text": "Apple beats earnings with record quarterly iPhone sales"}'

# Python (requests)
import requests
payload = {"text": "Apple beats earnings with record quarterly iPhone sales"}
res = requests.post("http://localhost:8000/sentiment", json=payload).json()
print(res)
# Output: {"label": "positive", "score": 0.8421, "probabilities": {"positive": 0.92, "neutral": 0.05, "negative": 0.03}}
  









5. DeBERTa-v3 Zero-Shot NLI Event Classification API



  Classifies headlines into 7 standardized financial event categories using Natural Language Inference (NLI):
  earnings, mergers_acquisitions, geopolitical, macroeconomic, 
  credit_event, product_launch, and other.





  
  

  







  How to Call Event Classification API (Code Examples)
  
# cURL (POST /classify)
curl -X POST "http://localhost:8000/classify" \
  -H "Content-Type: application/json" \
  -d '{"text": "Federal Reserve cuts benchmark interest rates by 50 bps"}'

# Python (requests)
import requests
res = requests.post("http://localhost:8000/classify", json={"text": "Boeing credit rating downgraded to junk"}).json()
print(res)
# Output: {"event_type": "credit_event", "confidence": 0.88, "scores": {...}, "model_votes": {...}}
  









6. Market Impact Score Estimation API (Score 1-10)



  Estimates market impact severity on a calibrated 1 to 10 scale. 
  Decomposes impact into quantitative sub-scores: financial magnitude ($B figures), urgency, geographic scope, confidence bonuses, and anti-stuffing caps.





  
  

  Event Type Override (optional):
  
   
  







  How to Call Market Impact API (Code Examples)
  
# cURL (POST /impact)
curl -X POST "http://localhost:8000/impact" \
  -H "Content-Type: application/json" \
  -d '{"text": "Tesla files emergency bankruptcy after $10B debt default", "event_type": "credit_event"}'

# Python (requests)
import requests
payload = {
    "text": "Tesla files emergency bankruptcy after $10B debt default",
    "event_type": "credit_event"
}
res = requests.post("http://localhost:8000/impact", json=payload).json()
print(res["impact_score"])  # e.g. 9.2
print(res["breakdown"])     # {"financial_magnitude": 3.0, "urgency": 2.5, ...}
print(res["reasons"])       # ["$10B+ transaction size detected", "Credit default trigger"]
  









7. Combined Full NLP Pipeline API (POST /analyze)



  Unified single-call endpoint that executes the full end-to-end NLP intelligence pipeline in one request:
  Ticker Extraction + FinBERT Sentiment + DeBERTa Event Classification + Market Impact Score (1-10).





  
  

  Ticker override (optional): 
   
  







  How to Call Full NLP Pipeline API (Code Examples)
  
# cURL (POST /analyze)
curl -X POST "http://localhost:8000/analyze" \
  -H "Content-Type: application/json" \
  -d '{"text": "Microsoft announces $15B acquisition", "tickers": ["MSFT"]}'

# Python (requests)
import requests
res = requests.post("http://localhost:8000/analyze", json={
    "text": "Apple surges on blowout earnings beating Wall Street consensus",
    "tickers": ["AAPL"]
}).json()
print(res["sentiment"])  # {"label": "positive", "score": 0.82}
print(res["event"])      # {"type": "earnings", "confidence": 0.91}
print(res["impact"])     # {"score": 7.8, "breakdown": {...}}
  









8. Alpha Signals & Multi-Window Signal Fusion



  Combines sentiment score, market impact, recency decay (24h half-life), and source agreement across observation windows (6h, 24h, 72h) into blended ticker trading signals in (-1.0, +1.0).





  
   
  







  How to Call Signals API (Code Examples)

# 2. Rich Multi-Window Signal Decomposition (GET /signals/rich)
